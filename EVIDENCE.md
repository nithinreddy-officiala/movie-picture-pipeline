# Evidence checklist

Capture your own screenshots after running the project. Do not reuse screenshots from another submission or from the course comparison examples.

Recommended evidence:

1. Frontend CI — successful lint, tests, and build.
2. Backend CI — successful lint, tests, and build.
3. Frontend CD — ECR push and successful EKS rollout.
4. Backend CD — ECR push and successful EKS rollout.
5. Frontend URL showing the movie list.
6. Backend `/movies` endpoint showing the JSON response.
7. A failed test run showing that the build does not proceed when tests fail.
